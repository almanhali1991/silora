# SiloraPro - نظام إدارة متكامل

نظام إدارة أعمال متكامل مبني باستخدام أحدث التقنيات.

## التقنيات المستخدمة

- **اللغة:** C#
- **الإطار:** .NET 10 LTS
- **الواجهة:** WPF بتصميم عربي حديث
- **المعمارية:** Clean Architecture + MVVM
- **قاعدة البيانات:** SQLite مع Entity Framework Core
- **إدارة الاعتماديات:** Microsoft.Extensions.Hosting
- **توليد PDF:** QuestPDF
- **التسجيل:** Serilog

## المميزات

- واجهة مستخدم عربية بالكامل (RTL)
- تصميم حديث واحترافي
- إدارة العملاء والمنتجات والطلبات
- لوحة تحكم شاملة
- سجلات تفصيلية للنظام
- تقارير PDF

## التشغيل

```bash
dotnet run --project src/SiloraPro.Presentation/SiloraPro.Presentation.csproj
```
